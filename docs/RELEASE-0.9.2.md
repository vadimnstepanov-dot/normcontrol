# Выпуск 0.9.2

Выпуск уточняет обработку доказательств и междокументных связей, повышает устойчивость заданий и исправляет отображение остановленной проверки.

## Изменения

- Стандартный контекст проверки увеличен до 49 152 токенов; бюджет ответа для логического этапа ограничен 4096 токенами. Подготовка задания обращается к его ключу напрямую, без чтения полных записей других заданий.
- Неподтверждённые требования нормативной базы могут участвовать в предварительном анализе по явной настройке. Такой анализ не подтверждает норматив и не подменяет решение эксперта.
- Цитаты из исходных документов проверяются и восстанавливаются по ссылкам на источники. Для междокументных заданий добавлены восстановление ссылок и компактные форматы передачи с явным включением.
- Воркер повторяет авторизацию после временной ошибки шлюза. Длинные ответы визуального этапа делятся на части; прозрачные изображения приводятся к белому фону перед проверкой.
- Уточнены правила для числовых фактов и языковых замечаний. Интерфейс корректно показывает остановленное состояние проверки.

## Проверка и границы применения

Публичные тесты запускаются командой `python tools/test_release.py` в окружении из `requirements-test.txt` и `requirements-test.lock`. Локально проверены 756 тестов: 755 успешно, один тест живой модели штатно пропущен. `pip check` и проверка синтаксиса браузерного скрипта прошли. Тестовый каталог и данные синтетические; пользовательские документы, нормативная база, результаты проверок и ключи доступа в выпуск не входят.

Компактные форматы междокументной передачи требуют отдельного включения. Выполнение задания или отсутствие замечаний не доказывает раскрытие каждого функционального требования. Связь с ПМИ может быть подтверждена только при наличии ПМИ. Ускорение полного цикла на реальном комплекте документов не подтверждено измерением для этого выпуска.
