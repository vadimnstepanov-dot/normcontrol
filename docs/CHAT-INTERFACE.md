# Чат и экспертный интерфейс

По умолчанию кабинет открывает чат: документы, запрос, фактическое состояние проверки и короткий итог. Реестр замечаний доступен в экспертном представлении через верхний переключатель «Эксперт». Переключатель меняет представление, но не права доступа.

## Новая проверка

Прикрепите DOC/DOCX, явно назначьте каждому файлу роль «Проверить» или «Как основание», напишите запрос и отправьте его. Нужен хотя бы один проверяемый документ. Одинаковые копии нельзя назначить одновременно проверяемым документом и основанием.

При выборе DOC в чате или экспертной форме сразу показывается предупреждение: сам документ можно проверить, но для Word с правками и примечаниями нужен DOCX. Предупреждение остаётся, пока в списке есть DOC, включая файлы, добавленные перетаскиванием. Проверка DOC не блокируется. Для гарантированного формирования Word загрузите исходник в DOCX: автоматический экспорт DOC возможен только после передачи обработчиком его точной рабочей DOCX-копии.

В экспертной форме новой проверки есть отдельное многострочное поле «Промпт пользователя». Указанные в тексте направления отмечаются в форме; окончательный набор определяют флажки, роли и нормативные наборы перед запуском. Текст сохраняется в беседе того же запуска и переносится при переключении представления. Произвольные дополнительные правила из свободного текста автоматически не создаются: распознаются известные направления проверки, без дополнительного вызова LLM.

Оба представления используют канонический приём файлов и запуск. Повтор того же подтверждённого запроса открывает существующий запуск. Изменение параметров старого запроса требует нового запуска. Документ-основание остаётся в контексте комплекта, но исключается из собственной проверки и из внесения правок.

Для СТО используется разрешённый пользователю опубликованный нормативный набор с закреплением версии. При неоднозначном выборе требуется уточнение; при отсутствии базы нормативная проверка не подменяется языковой.

## Состояние и файлы

Сообщение о ходе обновляется по сохранённым данным системы; служебные события не создают новые сообщения. Показываются реальные завершённые и запланированные задачи, без предполагаемого времени завершения. Пауза, продолжение, отмена и повтор используют действующие обработчики и права владельца.

Рядом с подписью NormControl показывается счётчик прошедшего времени тем же шрифтом. В очереди он подписан «В очереди уже»; во время обработки — «Работает уже». Секунды обновляются локально, без дополнительных запросов. После перезагрузки время восстанавливается по серверным отметкам. На паузе и после завершения счётчик останавливается; если точное время окончания старой проверки отсутствует, показана честная подпись «До последнего обновления».

Итог различает полную проверку, частичный результат, отмену и ошибку. Ноль замечаний при неполном охвате не означает соответствие. Чат не показывает отдельные замечания, цитаты или формы их разбора.

Excel содержит полный сохранённый реестр независимо от фильтров и пагинации. Word формируется отдельно, без повторного анализа, по проверенным адресам исходного документа; ссылка появляется только после готовности файла. Краткий отчёт также привязан к версии результата. Подробности Word: [WORD-REVIEW.md](WORD-REVIEW.md).

## Установка

Обновить исходники портала, выполнить миграции, `manage.py check`, `manage.py collectstatic`, затем штатно перезапустить веб-сервис. Миграции 0018–0020 добавляют предпочтения пользователя, переписки, сообщения и закреплённые роли. Предварительно сохраните базу и код для отката; миграция 0017 относится к Word-экспорту.

Для проверки пакетов с основаниями нужны обработчики, объявляющие `document-roles-v1`: локальный nc5 и нормативный knowledge_v2. Несовместимый обработчик не получает такую задачу. Портал и чат можно обновить отдельно; при сохранении старого обработчика задачи с основаниями будут ожидать совместимого исполнителя. Работающие закреплённые планы автоматически не переводятся на новую реализацию.

## Проверки и ограничения

`python tools/test_release.py` запускает синтетические тесты канонического запуска, идемпотентности, ролей, прав, истории, прямых ссылок, полного Excel, Word и конвейера. Проверка браузером должна дополнительно включать переключение с реальными File-объектами, сохранение неотправленной экспертной формы, темы, компактный экран и скачивание настоящих файлов.

Файлы до загрузки живут в памяти страницы; после полной перезагрузки их нужно выбрать заново. Содержимое файлов не сохраняется в localStorage. Опрос статуса выполняется каждые семь секунд только при видимой странице. Смена представления сохраняет открытый экспертный документ в iframe; полная перезагрузка страницы не восстанавливает все временные фильтры и неотправленные пояснения iframe.

Тестирование малого синтетического DOCX подтверждает работоспособность запуска и экспортов, но не полноту замечаний на произвольных технических документах и не ускорение большой проверки. Проверка настоящей мобильной клавиатуры и всех браузеров требует отдельного испытания на устройствах.
