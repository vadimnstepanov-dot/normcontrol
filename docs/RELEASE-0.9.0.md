# Выпуск 0.9.0

Нормоконтроль 0.9.0 развивает совместную проверку комплектов технических документов по закреплённым нормативным выпускам.

## Сопоставление шаблона СТО

Перед нормативным разбором новый прогон выбирает шаблон соответствующего профиля из оригинала СТО в закреплённом выпуске. Таблица сопоставления доступна в интерфейсе проверки и итоговых выгрузках Word/Excel. Структурное совпадение не трактуется как доказательство содержательной полноты. При неоднозначной версии шаблона система задаёт вопрос.

## Обновления платформы

Портал поддерживает управление нормативными областями, профилями, источниками, требованиями и глоссарием, экспертную роль, трассировку требований и журнал обработки. Состав задач, версии нормативов и модель фиксируются для воспроизводимости. Проверки поддерживают контролируемую постановку текста и изображений в очередь.

## Проверка этого выпуска

Автоматические проверки и сверка шаблона выполнены на реальном ОИТ ИСРАС. Результат реального сопоставления включал совпавшие заголовки, отличие заголовка одного пункта и условный элемент. Это не заменяет полную экспертную проверку содержания документов и нормативной базы.

Релизный исходный код не содержит пользовательских документов, нормативного корпуса, базы проверок, паролей, токенов либо файлов локальной модели.
