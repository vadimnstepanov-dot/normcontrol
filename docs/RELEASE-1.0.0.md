# Выпуск NormControl 1.0.0

Дата: 2 октября 2026 года.

Выпуск объединяет накопленные изменения портала, основного обработчика и нормативной базы. Сохраняются специализированные правила проверки, роли документов, права пользователей и история результатов.

## Изменения

- Свободный диалог с доверенной моделью и подбор опубликованных нормативных источников RAG с учётом доступа пользователя; долговременная очередь запросов и восстановление после остановки.
- Общая верхняя панель чата и эксперта, прикрепление документов через «+», история, темы, боковая панель и счётчик времени. Пустое задание использует пример проверки.
- Word с настоящими правками и примечаниями с разделом «Основание». Проверяемый документ и утверждённый эталон имеют разные роли; исходные файлы, прежние примечания и правки сохраняются.
- Прямой DOC-конвейер в native core: чтение XML-частей Word в памяти, сохранение DOC → DOC без промежуточного DOCX. DOCX продолжает обрабатываться напрямую.
- Основной обработчик, подготовка, планировщики, очередь и шлюз в WSL/Docker; модель, Word и аппаратная телеметрия остаются в Windows.
- Общая очередь допуска двух CPU-задач и одной GPU-задачи, резерв 2048 МиБ и кэш документов до 1024 МиБ с дополнительным ограничением памяти контейнера.
- Постоянный кэш подсчёта токенов, связанный с запросом и настройками модели. Обрезанные ответы сохраняются, отклоняются как неполные и обрабатываются ограниченными повторными попытками/разбиением.
- Страница плановых работ со сроком, сохранение checkpoint и защита пользовательских пауз при восстановлении.
- Актуальные README, инструкции Windows/Linux/WSL/Docker и четыре снимка интерфейса на учебном стенде. Переносимые пути запуска, адрес health-check из конфигурации и необходимые модули включены в Docker-сборки.

## Обновление

Сначала включите страницу плановых работ, дождитесь безопасной паузы и сохраните согласованную копию данных. Затем установите тег 1.0.0, зависимости/образы, миграции Django и статику. Проверки со старым закреплённым планом не переключаются автоматически на несовместимый обработчик; хэши не подменяются. Данные и старые результаты сохраняются. Подробности: [INSTALL.md](../INSTALL.md), [native core](../deploy/native-core/README.md).

Публичный выпуск содержит исходники. Модели, нормативные документы, рабочие базы, результаты пользователей, секреты и сертификаты не включены. Контейнеры собираются локально из исходников; готовые образы в публичном реестре не заявлены.

## Проверки и ограничения

Локально выполнены 980 Python-тестов: 979 успешно, один тест живой модели пропущен явно. Все 5 тестов поведения чата Node.js прошли. Проверка зависимостей не выявила конфликтов; сценарий запуска PowerShell прошёл синтаксическую проверку.

Из исходников собраны пять образов 1.0.0: нормативный базовый обработчик, native core, документный обработчик, обработчик эксперта и портал. Проверены необходимые импорты во всех образах, Django check портала, зависимости native core и синтаксис Compose. Контейнеры проверки запускались без сети и без рабочих данных. Ссылки на CI Windows/Ubuntu приведены в GitHub Release.

Точная обработка DOC требует Windows-моста и Microsoft Word. Старый автономный Windows CLI продолжает использовать рабочую DOCX-копию. Защита документа, неоднозначные диапазоны и неподдерживаемые изображения остаются явными ограничениями.

Успешные тесты не доказывают полноту нормативного корпуса или функционального покрытия конкретной проверки. Невыполненный этап не является успешной проверкой; кандидаты и вопросы не превращаются автоматически в подтверждённые нарушения. Полная длительность зависит от документа, числа задач, доступной RAM и модели.
