# Выпуск 0.9.1

Исправлена подготовка DOCX в чистой установке. Добавлены воспроизводимые тесты и
измерения времени, позволяющие отделить подготовку документа, планирование,
ожидание очереди и работу модели.

## Исправления и тесты

- Импорт отсутствующего модуля `quality_review` заменён на `document_units`.
- Публичные тесты используют синтетический каталог, не требуя частных нормативов.
- Обработчик журнала корректно работает с минимальными записями заданий.
- Добавлены фиксированные зависимости и CI для Windows/Linux.
- На чистом локальном окружении Python 3.12 прошли 653 теста; один из 654 тестов
  пропущен, поскольку требует явного включения живой LLM. `pip check` успешен.

## Измерения производительности

Числовой журнал доступен для nc5 и Knowledge v2. Он показывает вложенные стадии,
число служебных запросов, попадания в кеш, очередь, генерацию и перепроверку.
Серверные prefill/decode сохраняются, если сервер их предоставляет. Возобновления
добавляют отдельные сессии. Тексты документов, ответы модели и ключи доступа в этот
журнал не включаются. Ошибка его записи не отменяет результат проверки.

Добавлен `tools/benchmark_document.py` для измерений CPU, точного подсчёта токенов
и повторного построения сохранённого плана без генерации ответов.

[Установка тестового окружения и использование измерений](release-performance.md).

## Обновление и ограничения

Обновите код и перезапустите соответствующие воркеры после завершения текущих
проверок. Действующие задания nc5 закрепляют хеш реализации: продолжение задания,
созданного другой версией кода, может потребовать исходную версию или новый запуск.
Автоматическая миграция нормативной базы для этих изменений не требуется.

Измерения начинаются с выполнения задания воркером; браузерная загрузка и очередь
до назначения воркера не входят в них. Изменения не обещают ускорения генерации и
не меняют правила нормативных решений или алгоритмы векторного поиска.
Пользовательские документы, нормативные базы и частные результаты измерений
в состав релиза не включены.
