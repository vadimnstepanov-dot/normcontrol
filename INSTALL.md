# Выбор варианта установки

Проект поддерживает два самостоятельных варианта установки:

| Вариант | Для чего подходит | Инструкция |
|---|---|---|
| Windows 10/11 | Локальная LLM с GPU, обработка `.docx` и `.doc`, проверка свойств Word, локальный UI или worker | [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md) |
| Linux | Портал на VPS, локальный движок для `.docx` или worker рядом с Linux-сервером llama.cpp | [INSTALL-LINUX.md](INSTALL-LINUX.md) |

Рекомендуемая корпоративная схема: портал работает на Linux/VPS, а worker, Microsoft Word и LLM — на Windows-компьютере с GPU. Портал хранит пользователей и очередь; ресурсоёмкая обработка остаётся на рабочей станции.

## Что потребуется в обоих вариантах

- Python 3.11 или 3.12;
- Git;
- OpenAI-совместимый API локальной модели для выполнения проверок;
- нормативные документы, которые организация вправе использовать;
- отдельные случайные секреты для производственного портала и worker.

Модель GGUF, тексты СТО, пользовательские документы, рабочие базы и секреты в репозиторий не входят.

## Проверенный объём установки

Инструкции проверены в чистом каталоге: создание виртуального окружения, установка зависимостей, импорт модулей, миграции Django, системная проверка и 33 теста портала. Полные 116 тестов движка требуют предварительно собранного тестового каталога нормативных требований.
